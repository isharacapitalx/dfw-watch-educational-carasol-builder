# Posting time guidance (Phase 4)

General best-practice guidance, not Arwa-account-specific data — there's no Instagram Insights access yet to personalize this further. Researched 2026-07-29; re-check periodically since platform behavior drifts.

## Best windows (weekday)

- **Morning:** 8-10am (pre-work scroll)
- **Lunch:** 11am-1pm (people have a few free minutes to actually swipe through a carousel)
- **Evening:** 6-9pm (post-work wind-down — the strongest window for carousels specifically, and also when real-estate audiences browse listings after work)

## Best/worst days

- **Strongest: Tuesday-Thursday** — consistently the highest early engagement for carousel-format posts specifically.
- **Weak: Friday-Saturday** — engagement drops across every time slot for carousels. Real-estate content is a partial exception (Saturday morning house-hunting browsing is a real pattern), but the carousel-format data outweighs it — avoid Fri/Sat evening posts especially.
- **Sunday:** moderate, evening window still works reasonably.

## How to apply in Phase 4

Give a same-day recommendation based on what day/time it currently is — don't suggest delaying to a different day, the goal is same-day posting at a good window within today, not chasing the theoretical best day at the cost of cadence:
- If it's currently morning (before ~10am): recommend posting within the 8-10am window if there's still time, otherwise the lunch or evening window today.
- If it's midday: recommend the 6-9pm window today.
- If it's already evening: recommend posting now if within 6-9pm, otherwise note tomorrow's morning window as the next good slot.
- Always mention if today is a Tuesday-Thursday (say so as a plus) or a Friday/Saturday (note engagement tends to run lower, but still recommend the best window within today rather than suggesting a delay).
